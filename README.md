# odin-recipes
Repositório criado como estudo The Odin Project

Este projeto foi desenvolvido a partir de estudos iniciais em HTML, com posterior aplicação de CSS para estilização e personalização da interface.

Durante o desenvolvimento, foram aplicados conceitos fundamentais como alinhamento e centralização de elementos (em bloco e em linha), redimensionamento, controle de proporção de imagens e adaptação de layout. O projeto também aborda princípios de responsividade, garantindo que, independentemente do tamanho da imagem ou da janela do navegador, os elementos permaneçam visíveis e organizados na tela.
